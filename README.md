# グループ制御中のアイテムで画面分割（拡張）
制作者:HAIsan

## 概要
「グループ制御中のアイテムで画面分割」エフェクトを独自に改造した「グループ制御中のアイテムで画面分割（拡張）」を追加するプラグインです。

※元の「グループ制御中のアイテムで画面分割」エフェクトも引き続き使用できます。

## インストール方法
[ここからダウンロード](https://github.com/HAIsanGames813/ExtendedScreenSplit/releases/latest)

## 使用方法
映像エフェクトの「配置」タブに「グループ制御中のアイテムで画面分割（拡張）」が追加されます。

円状・線状・グリッド状の画面分割が可能です。

並びの開始位置や分割数など、細かい設定が可能です。

また、分割箇所ごとに幅を広げたり、境界に線を追加したりすることもできます。

# ExtendedScreenSplit
Author: HAIsan

## Overview
A plugin that adds an enhanced version of the "Screen Split for Items Under Group Control" effect, with additional customization options.

The original "Screen Split for Items Under Group Control" effect remains available and can still be used.

## Installation
[Download here](https://github.com/HAIsanGames813/ExtendedScreenSplit/releases/latest)

## How to Use
The following effect will be added to the **Layout** tab of Video Effects:

- **Extended Screen Split for Items Under Group Control**

This effect supports three types of screen splitting:

- Circular
- Linear
- Grid

You can customize various settings, including the starting position of the arrangement and the number of divisions.

Additional options allow you to adjust the width of individual sections and add lines along the boundaries between sections.
